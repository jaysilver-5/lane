# Internal HTML companion

This is a separate static design/interaction simulator, retained for internal review. It is not the React Native app, a native SDK test, a production account system or a real payment checkout.

Demo/test warnings and QA controls are intentional here. It uses local simulated state and must not be published as the customer app. Current browser screenshots in `qa/v4/` document this companion and the static landing page only.

Rebuild with `npm run preview:build`, then serve locally with `npm run preview`. Canonical commercial copy is CA$14.99 once. Never host the repository root or authoring question bank publicly.
